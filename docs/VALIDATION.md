# Проверки AxisPlanner 0.1.0

Дата: 7 ноября 2026 года. Проверки выполнены локально, без загрузки на оборудование.

## Нативные интеграционные проверки

Windows x86_64, Zig 0.13.0 / Clang, C++11. Используются настоящие исходники `AxisCore.cpp`, `AxisProfile.cpp`, `AxisSync.cpp`, заголовки GyverMotor2/StepperCore и адаптеры Axis/AxisStepper. Только Arduino GPIO/время заменены тестовой средой. Версии зависимостей закреплены в [DEPENDENCIES.md](DEPENDENCIES.md).

```console
python tests/run_tests.py --sanitize
```

Проверены:

- Размеры и заполнение очереди, неверные индексы, повторное подключение одного Core, NaN, дублирующиеся точки и программные границы.
- Запрет старта без homing, при занятости оси и при ненулевом `maxJerk`.
- Согласованное движение шаговой/DC-осей, разные контрольные периоды, ограничение подачи по медленной оси.
- Фактическое установление по позиции/скорости, однократный `ready()`, завершение на всех осях.
- Добавление относительных точек в движении, сохранение активного профиля, повторное использование кольцевой очереди.
- Обязательная остановка с сохранением продолжения, `resume()`, разворот и повороты с `dtA = 0` / `0.3`.
- Асимметричные разгон/торможение, короткие отрезки, переход нескольких отрезков в пределах одного обслуживания.
- Плавный `stop()`, в том числе с тормозным путём через границу отрезка; отмена остатка маршрута и `Completion::STOPPED`.
- Ошибка концевика второй оси между циклами управления: новые выходы первой оси не выдаются.
- Отказ чтения обратной связи, задержка обслуживания, потеря владения, общий сброс ошибок и немедленное торможение.
- Переполнение 32-битного счётчика времени.
- Реальный `AxisStepper<STEPPER2WIRE, STEPPER_VIRTUAL>`: homing по моделируемому датчику и перемещение по фактически выданным шагам; отдельный масштаб внешнего энкодера и ошибка слежения при замороженной обратной связи.
- Группа из четырёх осей: два DC и два шаговых двигателя, включая неподвижную компоненту.
- Компиляция обоих примеров как C++11 с настоящими заголовками драйверов.

Модель DC-двигателя содержит механическую задержку и квантованный энкодер; обратная связь не подменяется опорной позицией. Модель шагового привода интегрирует выходную скорость Axis. Отдельный тест виртуального драйвера считает реальные вызовы StepperCore.

Число проверок в выводе — число утверждений, включая проверки на каждом цикле модели; оно не означает столько же независимых сценариев. Проверки с UndefinedBehaviorSanitizer не выявили ошибок.

## Сборка для Arduino

Arduino CLI 1.5.1; Arduino AVR Boards 1.8.8; avr-gcc 7.3.0-atmel3.6.1-arduino7.

```console
python tests/compile_examples.py --cli /path/to/arduino-cli --board arduino:avr:mega
```

При отдельной конфигурации CLI добавьте `--config /path/to/arduino-cli.yaml`. Скрипт использует закреплённые зависимости, пишет сборки и логи в `.build/`, прошивку не загружает.

| Плата | Пример | Flash | Статическая RAM | Результат |
|---|---|---:|---:|---|
| Mega 2560 | MixedXY_Mega | 48194 байт | 2066 байт | Компиляция и линковка успешны |
| Mega 2560 | StepperXY | 45162 байт | 2084 байт | Компиляция и линковка успешны |
| Uno ATmega328P | StepperXY | > 32256 байт | > 2048 байт | Превышены Flash и статическая RAM |

Запас стека и длительность обслуживания на платах не измерялись. Сокращение очереди снижает расход RAM, но само по себе не устраняет превышение Flash на Uno. Примеры рассчитаны на Mega или платформы с большим объёмом памяти; сборка для ESP32 в этой работе не выполнялась.

## Границы проверки

Реальные двигатели, силовые драйверы, энкодеры и концевики не испытывались. Не подтверждены предельная частота шагов, время выполнения `tick()`/перепланирования, запас стека, устойчивость DC-регулятора и тормозной путь механики. Нативные модели проверяют программную логику.

Повороты с ненулевой скоростью используют приближение GyverPlanner2 без геометрического скругления. Тесты не доказывают непрерывность векторной скорости в таких вершинах. Ограничение рывка не реализовано и явно отклоняется при старте.

GitHub Actions workflow добавлен для нативных проверок; удалённый запуск не выполнялся.
